# 충곽 뭐해 Android

사용자 본인의 Teams·Classroom 계정으로 로그인하고 기기에서 직접 과제와 제출 상태를 읽는 앱입니다. 별도 서버나 데스크톱 연결을 요구하지 않습니다. AI 개발실은 Windows 프로그램에만 있습니다.

## 동작

- 공식 Google 인증 화면 및 Microsoft 브라우저 인증(PKCE)을 사용합니다. 비밀번호를 앱이 수집하지 않습니다.
- 30분·1시간·2시간·6시간 중 선택한 간격으로 WorkManager가 두 서비스를 확인합니다. Android 절전 정책에 따라 실행은 늦어질 수 있습니다.
- 한국 시간 기준 마감 일주일 전·하루 전·당일에 알림을 예약합니다. 제출 확인·내 작업 완료·지난 기한은 예약에서 제외하고, 원본에서 제출을 취소하면 다시 예약합니다.
- 알림 직전에도 원본 상태를 확인합니다. 오프라인이면 최근 저장된 상태라는 안내를 알림에 표시합니다.
- Classroom의 마감 없는 항목은 학습자료로 구분합니다. 파일은 이름과 원문 링크만 보관하고 파일 내용은 내려받지 않습니다.
- 계정·수업·원본 ID로 항목을 식별하며 갱신 시 개인 메모와 완료 표시를 유지합니다. 목록에서 사라졌다는 이유로 삭제하거나 제출 처리하지 않습니다.
- 인증 정보는 Android Keystore로 암호화하고 과제는 앱 전용 SQLite에 보관합니다. 앱 데이터의 클라우드 백업·기기 이전은 제외합니다.

## 사용자 연결과 배포자 등록

사용자는 앱에서 자신의 학교 이메일을 입력하고 공식 로그인 화면에서 읽기 동의를 진행합니다. 개발 콘솔이나 앱 ID를 입력하는 화면은 없습니다.

배포자는 Google과 Microsoft에 **앱 자체를 한 번 등록**해야 합니다. 배포자의 Google 비밀번호·쿠키·토큰은 APK에 넣지 않습니다. 앱 등록용 공개 식별 정보는 사용자 인증 정보와 다릅니다.

Google과 Microsoft의 공개 앱 식별자는 등록되어 APK에 포함됩니다. Google 앱은 프로덕션으로 게시했으나 민감한 범위 검증 전 사용자 100명 한도가 있습니다. Teams 과제 읽기 권한은 학교 관리자 동의가 필요하며 현재 학교 테넌트에 허용되지 않았습니다. 학교의 미성년 교육계정 정책도 적용됩니다. 등록 상태와 배포 전 확인은 [배포 준비](../docs/ANDROID-PUBLISHING.md)를 참고하세요.

## 빌드

JDK 21, Android SDK 35, Build Tools 34.0.0 이상을 사용합니다.

```powershell
# SDK 위치를 android/local.properties에 지정한 뒤:
.\scripts\Build-Android.ps1
```

Windows의 한글 경로에서는 빌드 스크립트가 임시 드라이브를 연결한 뒤 작업 종료 시 해제합니다. 서명 키는 Git에서 제외하는 `data/android-signing.properties`에서 읽으며, 실제 배포용 키는 운영자가 별도 보관합니다.

Linux/macOS 또는 영문 경로에서는 `cd android && ./gradlew testReleaseUnitTest lintRelease assembleRelease`로 빌드할 수 있습니다. 서명 설정이 없으면 release APK는 서명되지 않습니다. 테스트는 합성 데이터로 실제 저장·알림 API를 검사하며 학교 실계정 시험을 대신하지 않습니다.
