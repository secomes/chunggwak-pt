# 충곽 뭐해 개인정보 안내

충곽 뭐해는 무료 학교용 일정 앱입니다. 앱을 설치한 사람은 자신의 Google Classroom 및 Microsoft Teams 계정으로 각 서비스의 공식 로그인 화면에서 로그인합니다. 앱은 비밀번호를 받지 않습니다.

앱은 계정 이메일, 수업·과제 제목과 내용, 마감일, 제출 상태, 첨부파일 이름·링크와 로그인에 필요한 접근 권한을 사용합니다. 이 정보는 해당 사용자의 기기에서 과제 목록과 알림을 만드는 데 사용됩니다. Android에서는 인증 정보를 기기 보안 저장소에, 일정은 앱 전용 저장소에 보관합니다. Windows에서는 사용자별 로컬 프로필에 보관합니다.

앱에는 공용 운영 서버가 없으며 개발자에게 사용자의 과제나 로그인 토큰을 전송하지 않습니다. Google과 Microsoft에 대한 API 요청은 사용자의 기기에서 각 제공자에게 직접 전송됩니다. Windows의 선택 기능인 Notion 연결과 AI 개발실은 사용자가 별도로 연결한 서비스로 요청을 보냅니다.

앱에서 계정 연결을 해제하거나 앱 데이터를 삭제하면 기기에 저장된 연결 정보와 일정이 제거됩니다. Google 또는 Microsoft 계정의 보안 설정에서도 앱 권한을 철회할 수 있습니다. 서비스 문의: kjsssss38@gmail.com.
