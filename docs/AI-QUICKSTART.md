# AI 개발실 빠른 시작

1. 충곽피티에 자신의 사용자 계정으로 로그인하고 **AI 개발실**을 엽니다.
2. **ChatGPT로 로그인**을 눌러 본인의 ChatGPT 계정을 연결합니다. 충곽피티 로그인과는 별도입니다.
3. 필요하면 **코드로 로그인**을 사용하고 표시되는 로그인 안내를 따릅니다.
4. 다른 사람의 계정을 공유하지 마세요. 대화와 변경안은 충곽피티 사용자 계정별로 관리됩니다.
5. 입력창에 원하는 기능, 기대 동작, 수정할 범위를 적고 **요청 보내기**를 누릅니다.
6. 비밀번호·토큰·개인 자료는 요구사항에 넣지 마세요. 보안·서버·설정 파일 수정은 지원하지 않습니다.
7. 개발이 끝나면 **개발 변경안 → 변경 내용 보기**에서 설명과 파일별 전체 내용을 검토합니다.
8. 요청한 범위인지, 기존 기능·계정 분리·보안 검사를 유지하는지 확인합니다.
9. 변경안은 자동 적용되지 않습니다. 공용 프로그램 변경은 이 컴퓨터의 운영자가 검토 후 **확인한 변경안 적용**을 누릅니다.
10. 적용 결과를 확인하고 변경한 기능과 기존 기능이 정상적으로 동작하는지 점검합니다.
